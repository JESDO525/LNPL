# Tutorial de Jetpack Compose

Este proyecto es el resultado de seguir el instructivo oficial de Jetpack Compose. Jetpack Compose es un moderno kit de herramientas para crear interfaces de usuario nativas de Android. Simplifica y acelera el desarrollo de la interfaz de usuario en Android con menos código, herramientas potentes y API intuitivas de Kotlin.

En este proyecto, se ha construido un componente de interfaz de usuario simple con funciones declarativas, sin editar ningún diseño XML ni usar el editor de diseño. En su lugar, se utilizan funciones que admiten composición para definir los elementos deseados, y el compilador de Compose se encarga del resto.

## Lo que he aprendido

- Cómo definir funciones de componibilidad.
- Agregar distintos elementos al elemento componible.
- Estructurar un componente de IU con elementos de diseño que admiten composición.
- Ampliar elementos componibles con modificadores.
- Crear una lista eficiente.
- Hacer un seguimiento del estado y modificarlo.
- Agregar interacción del usuario a un elemento componible.
- Agregar animaciones cuando se expanden mensajes.

## Resultado

Se ha creado una pantalla de chat sencilla que muestra de manera eficiente una lista de mensajes expandible y animada, que contiene una imagen y textos diseñados con los principios de Material Design, un tema oscuro y vistas previas.
